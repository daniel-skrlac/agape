# Agape

**Agape** is a mobile-first application created to support charities, social supermarkets, community services, and local aid organizations in their everyday work.

The name comes from the Greek word *ἀγάπη* (*agape*), meaning unconditional love. The idea behind the project is simple: use technology to make helping others easier, faster, and more organized.

---

## 🌟 Purpose

Many community organizations work with food, essentials, donations, partners, recipients, warehouses, and paper documents every day.

Agape helps simplify that work.

Instead of relying only on paper notes, manual calculations, and repeated data entry, Agape gives users a digital tool for managing stock, preparing dispatches, using reusable templates, and scanning paper documents into the system.

The goal is to save time, reduce mistakes, and help organizations focus more on people and less on administration.

---

## ✨ What Agape Helps With

* 📦 **Warehouse overview**
  See available stock, missing items, and items that need refill.

* 🧾 **Dispatch preparation**
  Prepare goods for partners or recipients in a structured and reusable way.

* 📋 **Templates**
  Create reusable dispatch templates for common needs, such as packages for different household sizes.

* 🤝 **Partners and recipients**
  Manage the people, organizations, or services receiving goods.

* 📷 **Paper slip scanning**
  Scan dispatch slips and convert them into digital data to reduce manual typing.

* 📚 **Booking history**
  Review previous dispatches and track what was prepared or delivered.

---

## 💡 Why Agape?

Agape is built around one simple idea: community work should be easier to organize.

The app helps by:

* reducing repetitive manual work
* making warehouse information easier to access
* helping users prepare aid faster
* improving accuracy when working with paper documents
* supporting more transparent and organized community service
* creating a foundation for future donor and volunteer features

---

## 🚀 Vision

Agape is more than just a warehouse or dispatch tool.

The long-term vision is to become a platform that helps local communities coordinate generosity, donations, volunteering, and support for people in need.

The current version focuses on the practical foundation: stock, partners, templates, dispatches, and document scanning.

Future versions can expand toward donor coordination, volunteer scheduling, urgent needs, notifications, and community impact tracking.

---

## 🛠️ Tech Overview

Agape is built as a modern mobile and backend application.

* **Mobile app:** React Native / Expo
* **Backend:** Java / Quarkus
* **Database:** PostgreSQL
* **Legacy integration:** Oracle database
* **Scanning service:** Python OCR service
* **Hosting:** Self-hosted with Docker
